# 参数表：默认值、出处、怎么调

所有数字都有理由。调之前先看"为什么是这个值"，否则很容易调出"看起来差不多但读起来不对"的结果。

## 一、画幅与节奏

| 参数 | 默认 | 出处 |
| --- | --- | --- |
| 画幅 | 1920×1080 / 30fps | 横屏 16:9。竖屏投放不要改画幅，改构图（见下） |
| 段落数 | 3–6 | 少于 3 段不必用接力；多于 6 段每段不足 5 秒，观众来不及读 |
| 单段时长 | 5–9s | 低于 5s 走来走去没有"经过"的感觉 |
| 重叠期 | 1.8s（35s 片） | 约占总长 5%。短片 1.0–1.2s，长片 2.4–2.8s |
| 首尾黑场 | 淡入 0.67s / 淡出 1.0s | 淡入短于画面起幅，淡出长于音乐收尾 |

竖屏投放的处理：画幅仍是 1920×1080，但把人物横向活动范围收到 0.35–0.65，
地貌主体放在中间 1:1 安全区内。**不要直接改画幅**——改画幅会让整套曲线失效。

## 二、接力

| 参数 | 默认 | 为什么 |
| --- | --- | --- |
| `overlap` | 1.8s | 见上表 |
| `enterDone` | 0.62 | 新地貌在重叠期 62% 处显影完；提前是防"两层同时半透明→发暗" |
| `exitStart` | 0.36 | 旧地貌 36% 才开始退；再早会和新地貌抢时间 |
| `exitSpan` | 0.6 | 36% → 96% 退完；留 4% 余量防止端点抖动 |
| `sink` | 70px | 约占画面高 6.5%。太小读不出"退走"，太大会让地面明显滑移 |

可调的组合只有一个方向：**要更"慢"就同时增大 overlap 和 sink**，不要单独拉长其中一个。
只加 overlap 会让两层同时清晰的时间变长（重影风险），只加 sink 会让地面像电梯。

## 三、雾带

| kind | 高度占画面 | 峰值不透明度 | 模糊半径 | 用在哪 |
| --- | --- | --- | --- | --- |
| `cloud` | 38% | 0.72 | 44px | 云海 → 任何 |
| `sand` | 32% | 0.58 | 40px | 沙丘/干燥地表 |
| `spray` | 28% | 0.62 | 38px | 海边/水汽 |
| `snow` | 36% | 0.70 | 46px | 雪原/寒带 |

三条不可动的约束：

1. **模糊半径 ≥ 38px**（在 1920 宽下）。低于这个数会读成"白横条"。
2. **活动范围限制在画面 28%–88% 高度**。糊到上半幅会让观众觉得"天变了"。
3. **颜色从当前天色取**（`skyTintAt(sec).mist`），不写死白色。

## 四、镜头

| 参数 | 默认 | 为什么 |
| --- | --- | --- |
| `scale` 基准 | 1.09–1.16 | 必须全程 > 1，否则画框露边、地貌内侧断开 |
| `scale` 下限 | 1.05 | 硬下限，代码里用 `CAM_SCALE_FLOOR` 兜住 |
| 推近速率 | ≤ 1.0%/秒 | 超过会读成"机器在动"而不是"人在走" |
| 后拉起点 | 片尾前 6–9s | 太早会和人转身撞在一起 |
| 后拉幅度 | ≤ 6% | 15% 以上会被感知为"被拽走" |
| `transformOrigin` | 50% 61% | 对齐地平线附近，推近时地面不动 |

## 五、音频

| 参数 | 默认 | 为什么 |
| --- | --- | --- |
| 匀速可用上限 | r ≤ 1.06 | 6% 以内人耳分不出 |
| 连续变速区间 | 1.06 < r ≤ 1.40 | 超过就该改结构 |
| 片尾倍率 `e` | 0.84 | 慢 16%。低于 0.80 开始"拖" |
| 形状 `p` | 1.0（线性） | `p=2` 把减速堆到后 1/3，主观更拖 |
| 命令间隔 | 0.2s | 更密没有收益；rubberband 自己会平滑 |
| 淡入 | 0.42s | 画面 0.67s 起幅，音频晚于画面 |
| 淡出 | 1.7s | 结束在画面全黑前约 0.1s |
| 响度 | −14 LUFS | 短视频平台通用 |
| 真峰 | ≤ −1.5 dBTP | 留 1.5dB 给 AAC 编码过冲 |
| 增益 | 线性 −2.5dB | **不用 limiter**，动态小的素材会抽吸 |

## 六、人物

| 参数 | 童年 | 壮年 | 老年 | 单位 |
| --- | --- | --- | --- | --- |
| 身高 | 150 | 215 | 185 | px |
| 步频 | 2.05 | 1.55 | 0.30 | 步/秒 |
| 步幅 | 1.15 | 1.0 | 0.16 | 系数 |
| 驼背 | 0 | 0.34 | 0.88 | 0–1 |
| 前倾 | 6 | 4 | 10 | 度 |

- 身高跨度 **不小于 1.35 倍**，否则观众读不出年龄变化。
- 步频降到 0.3 以下时，画面里的人会像"原地挪"，那是对的 —— 老人本来就走不快。
- 人物宽度 = `h × (120/200) × 1.02`。改 viewBox 比例要同步改 `figWidth`。

## 七、验收阈值

| 指标 | 阈值 | 怎么测 |
| --- | --- | --- |
| 相邻帧整帧灰度差 | ≤ 8 | `ffmpeg -vf scale=1:1:flags=area -pix_fmt gray` |
| 最外圈像素 | 不能是纯底色 | 采样第 0/1/4 行的灰度，第 0 与第 4 不应突变 |
| 拍长前后差 | ≤ 60ms | `scripts/beatcheck.py` |
| 视频包 md5 | 换音轨前后一致 | `ffmpeg -map 0:v -c copy -f md5 -` |
| 响度 / 真峰 | −14 LUFS / ≤ −1.5 dBTP | `ffmpeg -af loudnorm=print_format=json` |
| 单帧渲染耗时 | ≤ 0.25s | 35s/1050 帧应在 4 分钟内渲完 |

## 八、参数之间的耦合（重要）

调参时最容易忽略的三组耦合：

1. **重叠期 × 镜头推近**：重叠期越长，推近速率要越低。否则 1.8 秒里既在地貌交接又在快速缩放，
   看起来像"镜头抖了一下"。
2. **片尾倍率 × 人物步频**：两者都在降速。人慢 70% 而音乐只慢 16% 会"脱拍"；
   人慢 70%、音乐慢 26% 才接近同步。改一个要回头看另一个。
3. **雾浓度 × 天色亮度**：雾是提亮物。天色本身很亮（烈日段）时雾要降 0.1–0.15，
   否则会读成"过曝"而不是"起雾"。
