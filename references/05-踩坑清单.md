# 踩坑清单

每一条都是实际踩出来的。写法统一为：**症状 → 根因 → 解法 → 怎么确认修好了**。
遇到"看起来差不多但读起来不对"的时候先来这里查，不要凭感觉调参数。

---

## 1. 每段切换时"闪一下"

**症状**：每 6–7 秒画面亮度猛地跳一下，像换了一张图。加了闪白遮罩反而更明显。

**根因**：不是遮罩问题。每段各有一套天空配色、一套镜头参数、一个主角。
叠化时天空在融色、镜头缩放不同、两个人物重影 —— 三条同时发生。

**解法**：提成三个全局层（`sky01.ts` / `makeCamera` / `Hero01`），地貌才用接力。

**确认**：逐帧测整帧灰度，相邻帧最大差 ≤ 8。

---

## 2. 新地貌"淡入"时画面暗一下

**症状**：转场中段画面整体发灰、发暗，像蒙了一层。

**根因**：新地貌从透明淡入，旧地貌同时淡出。两三层半透明叠在一起，
中间透出底色（天空/暗部），混色后整体变暗。

**解法**：新地貌不从透明开始，它从一开始就实心待在旧的**下面**，被露出来。
`enterDone = 0.62` 保证它在旧地貌开始退之前就已经满。

**确认**：转场中段抽帧，地面区域不应出现灰色蒙版感；灰度曲线在重叠区不应有凹陷。

---

## 3. 雾带看起来像一条白色横条 / 扫描线

**症状**：转场处出现一条横向的均匀白带，边缘整齐，像老电视的扫描线。

**根因**：用了 `blur(18px)`。在 1920 宽的画面里，18px 根本不算模糊。
而且形状是一条规则矩形带 —— 人眼对水平直线极敏感。

**解法**：改七团椭圆错落叠加（y 各差 4–9%），`blur` 提到 38–46px，
外圈再套一层 1.5 倍模糊的化边。`sin^0.6` 浓度曲线保证两端为零。

**确认**：抽转场最浓那一帧，雾的边缘不应有可辨认的直线段。

---

## 4. 全局主角和段落配角重叠成黑影

**症状**：12–14 秒画面右下角出现一团糊掉的黑影，像是两个人物叠在一起。

**根因**：把主角提到全局之后，他的 x 曲线（0.50）撞上了该段自己的配角（情侣 0.535）。
之前每段独立时不会碰，因为那时"主角"是段内的，位置由段自己定。

**解法**：把配角挪开（情侣改到 0.655），并在时间轴上核对：
主角的 x 范围与每个配角的 x 范围不能在同一秒重叠超过 0.02。

**确认**：把主角 x 曲线和所有配角位置画在同一张时间轴上，看有没有交叉窗口。

---

## 5. 拉长的音频听起来"怪"：空、薄、金属

**症状**：分段拉伸后，每 2 秒左右有一次音质断层，像隔了一层铁皮。

**根因**：分成 14 段 `atempo` 再交叉淡化。`atempo` 是 WSOLA，每次调用重置内部相位，
段边界两侧波形相位无关；等功率交叉只把**电平**接平，实际是两个不同相位信号相加 =
梳状滤波。

**解法**：改用 `rubberband` + `asendcmd` 一条滤镜连续变速。零接缝、零阶梯。

**确认**：听感上不应有周期性的"金属感"；拍长曲线逐窗单调平滑，无阶梯。

---

## 6. 以为 rubberband 没生效（其实是 `-t` 截断了）

**症状**：测 `rubberband=tempo=0.8`，输出正好 10.000 秒，和原速一样，判断"滤镜无效"。

**根因**：`-t 10` 放在 `-i` 之后，它是**输出时长**，不是输入时长。输出被截到 10 秒了。

**解法**：`atrim=0:10,rubberband=...`，或把 `-t` 放到 `-i` 之前。

**确认**：跑 10 秒的 `tempo=0.8`，正确输出应是 12.5 秒。

---

## 7. 用 `sendcmd` 改音频参数没反应

**症状**：写了 `sendcmd=f=cmds.txt`，报错或毫无效果。

**根因**：`sendcmd` 是**视频**滤镜版本；音频要用 `asendcmd`。

**解法**：`asendcmd=f=tempo_cmds.txt`。

---

## 8. ffmpeg 滤镜参数里的 Windows 路径解析失败

**症状**：`asendcmd=f='E:/xxx/tempo_cmds.txt'` 报 `No option name near ...`。

**根因**：滤镜参数解析器把 `:` 当成分隔符，`E:` 被切成两半。

**解法**：`subprocess(cwd=目录)` 后用纯文件名；或者转义成 `E\:/xxx`。

**确认**：命令能跑通且输出帧数正常。

---

## 9. 片尾边缘出现一圈硬边

**症状**：最后 7 秒，画面四周出现约 20px 的暗边，像画框露出来了。

**根因**：镜头 `scale` 跌到 0.895（< 1），整块画面缩进画框，露出 `AbsoluteFill` 的底色。

**更严重的连带问题**：地貌是"铺满整幅"画的，缩进去之后地面会在画面内侧断开、露出天。
那道断口比暗边明显得多，加模糊也救不了（糊的是边界，不是断口）。

**解法**：基准整体抬到 1.09–1.16，全程 > 1。代价是构图推近约一成，要重新核构图。

**确认**：采样画面最外圈像素（第 0/1/4 行的灰度）。有硬边的话第 0 像素会是纯底色、第 4 像素突变。

---

## 10. 雪堆看起来像一张桌子

**症状**：路旁的雪堆两侧是直线斜边、顶面是水平平台，读作"一张桌子"。

**根因**：人对直线边缘极敏感，而雪不可能有直线边。而且加了底部渐变淡出之后，
下半截透明，背景的雪脊从它肚子里穿过去 —— 变成"幽灵"。
拉到出画外改成深色，又读作"一块黑石头"或"一座塔"。

**解法**：矮（120px）、宽（260px）、雪色系（顶 `#8CA0C4` → 底 `#4A5878` 接雪原暗部）、
底边用**下凸弧**。直底边会被读成"贴上去的半圆"。

**确认**：抽帧看它是否读作"一个丘"，而不是"一个几何体"。

---

## 11. `alimiter` 让整体发闷、有抽吸感

**症状**：加了 limiter 之后，人声/主旋律在鼓点处被"吸"下去，整体能量反而更小。

**根因**：素材动态本来很小（LRA 2.2），limiter 反复触发，每次压一点点，
形成低频抽吸。而且真峰可能反而升到 +0.1 dBTP（削波）。

**解法**：去掉 limiter，纯线性增益 −2.5dB。

**确认**：`loudnorm` 测真峰 ≤ −1.5 dBTP，LRA 不应比原始素材更小。

---

## 12. `apad=whole_dur` 把还没淡完的音乐切断了

**症状**：片尾音乐突然消失，没有自然淡出。

**根因**：`apad` 补齐到目标长度后立刻 `atrim`，把正在淡出的尾巴截掉了。

**解法**：长度由变速曲线控制（积分到目标），`apad` 只做最后 1ms 级修整；
或者先实测实际长度再回算填充量。

---

## 13. 减速段腿在倒着抽

**症状**：人物步频下降时，腿突然反向摆一下，像抽搐。

**根因**：用 `t × cadence` 当相位。cadence 下降时这个乘积会**倒退**
（26s: 23.9 → 27s: 23.8），腿就倒着走。

**解法**：积出 `∫cadence dt` 当时间传进去，人物的 cadence 固定为 1。

**确认**：减速段逐帧看腿，摆动方向应始终单调推进。

---

## 14. 转身那一帧人变成一条竖线 / 两腿交叉

**症状**：回头时有一帧人物消失或腿部错乱。

**根因**：两个错误之一 —— ① 没跳过 `turn ≈ 0` 的那一帧，渲染了一条零宽的线；
② 用 `dir` 做转身，而 `dir` 参与逐点几何计算，翻面时腿的折向整体翻过来。

**解法**：`turn` 用外层 `scaleX 1→0→−1`；`abs(turn) > 0.03` 才绘制。

---

## 15. 音频"后面太拖"

**症状**：前 20 秒听着正常，最后 10 秒明显变慢、拖沓，像等它走完。

**根因**：把拉伸预算全押在片尾（0.955 → 0.740，慢 26%），且 `p=2` 把减速堆在后 1/3。

**解法**：摊平。0.920 → 0.840（慢 8% → 16%），`p=1` 线性。
总拉伸是固定预算，"前面慢"和"后面不拖"是同一件事的两面。

**确认**：起点与终点拍长差 ≤ 60ms。

---

## 16. 装了 ffmpeg 但没有 rubberband

**症状**：`ffmpeg -filters | grep rubberband` 什么都不返回；跑脚本报 `No such filter`。

**根因**：装的是 essentials / 精简构建，编译时没有 `--enable-librubberband`。

**解法**：换 full build（Windows 用 gyan.dev 的 `ffmpeg-release-full`，
macOS 用 `brew install ffmpeg`，Linux 用发行版的完整包）。装完确认：

```bash
ffmpeg -hide_banner -filters | grep rubberband   # 应有一行
ffmpeg -version | grep -o -- '--enable-librubberband'   # 应输出一次
```

`scripts/check_env.py` 会专门检查这一项，因为它是本技能唯一"看起来装了其实不能用"的依赖。

## 17. Windows 上两个文件只差大小写

**症状**：`Sky01.tsx` 和 `sky01.ts` 同时存在，TypeScript 报
`File name differs from already included file name only in casing`。

**根因**：Windows 文件系统不区分大小写，TS 判断为同一个文件。

**解法**：编号方案里避开这种组合。本技能用 `SkyParts01.tsx`（渐变元件）
和 `sky01.ts`（曲线工厂）区分开。

**通用规则**：同一个目录里不要出现只差大小写的两个文件名。

---

## 18. 关键帧插值用线性，动作在节点"顿一下"

**症状**：人物体态变化时，在某几秒出现轻微的"折角"感，像卡了一下。

**根因**：线性插值在斜率不同的相邻段之间，节点处一阶导不连续，形成折角。

**解法**：分段 smoothstep（`kf()`）。每个关键帧处一阶导为零，曲线连续可导。

**确认**：把曲线值逐帧打印出来，看一阶差分是否连续。
