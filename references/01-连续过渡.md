# 连续过渡：为什么"接力"不是"淡入淡出"

## 一、"闪"的三个真实来源

初学者会把"闪"归因于遮罩不好看，于是加闪白、加模糊、加黑场。都不管用，
因为根因是三样东西在每段各写了一遍：

| 来源 | 现象 | 观众读到的是 |
| --- | --- | --- |
| 每段一套天空 | 叠化时两套配色在"融"，中间透出底色，画面暗一下 | 换了一张图 |
| 每段一套镜头 | 段尾各自缓推，两张图的缩放不同 | 画面在抖/在跳 |
| 每段一个主角 | x、身高、foot 对不上，叠化时出现两个重影 | 一个人分成两个 |

三条都在，加什么遮罩都是"闪一下"。**必须先做全局化，再谈转场。**

全局化之后，全片只有一个"变"的维度：地貌。于是问题从"怎么切"变成"怎么交接"。

## 二、接力的时序

重叠期 `overlap` 秒。35 秒的片子里取 **1.8s**（约 5%）；60 秒取 2.4–2.8s；
15 秒以内取 1.0–1.2s。原则是重叠期至少容纳"一次呼吸"，但不要长到让两段同时清晰可见。

```
u = 重叠进度 0→1

新地貌 aIn  = smooth( clamp01(u / 0.62) )        // 前 62% 显影完
旧地貌 aOut = 1 - smooth( clamp01((u - 0.36) / 0.6) )  // 36% 起退，96% 退完
最终 opacity = min(aIn, aOut)
```

两个数为什么是 62% 和 36%：

- 新地貌如果和旧的同步变化，两者会同时半透明 → 中间透出天空 → 发暗 → 读作"闪"。
  提前到 62% 显影完，保证任一时刻最多只有一层是"半可见"。
- 旧地貌退得太早会和新地貌抢时间（同上）；退得太晚会留下 40% 以上的残留，
  它的人物会和新的叠成重影。36%/60% 实测下，两段同时半可见只有约 0.5 秒，
  且正好落在雾最浓的那一帧。

## 三、图层顺序：后段在下，前段在上

```
<Relay> 渲染时倒序遍历 scenes:
  star  ← 最先画，最底
  snow
  sea
  dune
  cloud ← 最后画，最上
```

新地貌**不从透明淡入**，它从一开始就是实心，只是被旧的挡着。
旧的退开一寸，新的就露一寸。

如果反过来（新的淡入），会出现两个问题：
1. 淡入过程中新的只有 30% 不透明度，底下是旧地貌的 30%，再底下是天空 —— 三层混色，发灰。
2. 淡入的"起点"是一个看得见的时刻，那又成了切换点。

## 四、退场为什么要下沉

只改 opacity 是"把整幅地貌等比擦掉"。地貌通常是铺满整幅画的，
擦掉的过程中底色（天空、暗部）会从地面位置透出来，看起来像"地面变薄了"。

加一个下沉位移（默认 70px，约占画面高 6.5%）：

```tsx
const dy = (1 - aOut) * sink;
style={{opacity: a, transform: `translateY(${dy}px)`}}
```

读作"地面从脚下退走，天空不动"。方向必须与运动方向一致 ——
人往前走，地貌往后/往下退。左右平移会读成"整个世界在横移"。

## 五、雾：转场真正发生的地方

雾不是装饰，它承担一个具体职能：**在两层交替的那 0.5 秒里提供合法的不清晰**。

四个要点（实现见 `code/Mist01.tsx`）：

1. **是团块，不是横条**。七团椭圆错落叠加，y 各差 4–9%，再上 40px 以上的模糊。
   一条均匀的横带在 1920 宽的画面上会读作"扫描线"或"白横条"。
   `blur(18px)` 在 1920 宽上根本不算模糊 —— 起步就要 38–46px。
2. **浓度曲线 `sin^0.6`**：两端为零、中段宽平。最浓的一刻正好是旧地貌退到一半的一刻。
3. **颜色从当前天色取**，不写死。云海的雾是暖白、沙丘是浅橙、雪原是冷白 ——
   雾永远"属于"当时的光。写死白色会在暖调段落里读成"起雾了"。
4. **只在 28%–88% 的画面高度活动**。从地平线升起、沉到脚下，不去糊上半幅的天空。
   天空是连续的，糊它反而让人觉得"天变了"。

## 六、天色要早于地貌半步

天色关键帧的时间点取在"该段主场的中点之后"，让它领先地貌半步。

做反了会怎样：天色和地貌同时换，观众觉得"两个东西一起变了"，注意力被分散；
天色早半步，读到的是"天先暗下来，脚下的地才跟着变"，而这正是真实世界里的次序。

示例片的天色关键帧：`0 / 6.6 / 9.4 / 13.0 / 15.6 / 19.6 / 21.8 / 25.6 / 28.4 / 35`，
对应"黎明 → 晨光 → 日头偏西 → 烈日 → 转金 → 日落 → 暮色 → 余晖散尽 → 星夜"。
注意它比地貌时间轴（`0 / 5.1 / 11.1 / 18.1 / 25.1`）更密 —— 天色是非线性的，
一个状态到另一个状态之间往往要两套色板（起点色 + 终点色）才够平滑。

## 七、怎么验证"真的没有闪"

不要靠肉眼。逐帧测整帧灰度：

```bash
ffmpeg -i out.mp4 -vf "scale=1:1:flags=area" -f rawvideo -pix_fmt gray - |
  od -An -tu1 -v | awk '{for(i=1;i<=NF;i++) print $i}'
```

得到一串 0–255 的亮度值，算相邻差：

- **≤ 8**：安全。人眼在 30fps 下看不出 8/255 的变化。
- 9–20：可疑，通常是某段自己在闪（粒子、字幕、光效），不是接力的问题。
- > 20：有真正的跳变，去那一帧抽图看。

示例片 1050 帧实测最大差 **6**，且只出现在首尾淡入淡出。

## 八、常见误判

| 现象 | 误判 | 实际原因 |
| --- | --- | --- |
| 片尾边缘一圈暗边 | "渐晕没做好" | 镜头 scale 跌到 1 以下，画框露出来了 |
| 地貌中间断开、露出天 | "遮罩没盖住" | 同上：地貌缩进画框，地面在画面内侧断开 |
| 雾看起来像白横条 | "模糊不够" | 形状问题。要团块，不是带 |
| 叠化时画面发灰 | "对比度没调" | 两张半透明叠一起，中间透出底色 |
| 人物在叠化时变两个 | "alpha 没算对" | 每段各画了一个人，没提成全局 |
